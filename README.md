# CareClaw（小棉袄）

**帮父母远程安装软件的端侧多模态 Android 智能体。**

孩子在外地发一句"帮妈装个微信"，CareClaw 在父母手机上自主完成：
检查已装 → 应用商店搜索 → 下载 → 安装 → 验证 → 回报结果。
父母也可以直接对着手机说"我要装 XX"，语音指令同样走 Agent 闭环执行。

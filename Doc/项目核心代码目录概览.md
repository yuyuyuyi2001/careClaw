# CareClaw 项目核心代码目录概览

> 本文件按**包/文件夹**逐层拆解 CareClaw 的源码结构，说明每个模块是干什么的、关键文件负责什么，并标注**超级核心模块**，方便按简历亮点对应阅读学习。
> 统计口径：`app/src/main/java/com/shijing/xomniclaw/` 下共 ~147 个 Kotlin 文件，总计 ~36.5K 行（`count_lines.ps1`，不计空行）。
> 标注说明：⭐⭐⭐ 超级核心（精读）；⭐⭐ 核心（通读）；⭐ 重要；无标注 = 辅助。

---

## 一、项目一句话

CareClaw 是**跑在 Android 手机上的端侧 AI Agent**（Observe–Reason–Act），帮不熟悉手机的长辈自动完成「远程装 App / 语音指令 / 相册问答」等任务。它通过无障碍树 + 截图感知屏幕 → LLM 推理 → 原子操作（点击/滑动/输入/装 App）→ 验证 → 回报，并把长期记忆（安装历史 + 使用画像 + 相册主题检索）沉淀下来。

对应简历 5 条亮点：
1. 混合感知 + 手机自动接管
2. Kotlin 端侧执行框架 + ORA 闭环 + 多会话
3. 双工具注册表 + 智能路由 + 循环检测
4. 多层记忆架构（工作记忆 + 相册检索 + 画像进化）
5. SKILL 固化 + 教学模式

---

## 二、核心数据流（一条指令的完整旅程）

```
远程/语音/ADB 指令
  → core/MyApplication + util/ChatBroadcastReceiver（入口）
  → core/MainEntryNew.runWithSession（全局编排，多会话隔离）
  → agent/loop/AgentLoop（ORA 循环：感知→推理→执行→验证）
      ├─ 感知：accessibility/（无障碍树 + 截图）
      ├─ 推理：agent/context/ContextBuilder（组 system prompt）→ providers/UnifiedLLMProvider（调 LLM）
      ├─ 执行：agent/tools/ToolCallDispatcher → AndroidToolRegistry / ToolRegistry
      │         └─ agent/tools/device/DeviceTool（屏幕操作）、InstallAppSkill（装 App）、memory/*（记忆）
      ├─ 验证：AgentLoop 循环检测 agent/loop/ToolLoopDetection
      └─ 回报：remote/（HTTP 入口）+ 会话落盘 agent/session/SessionManager
  → 记忆沉淀：agent/memory/MemoryManager（工作记忆）+ evolution/（画像）+ gallery/（相册）
```

## 四、逐包详解

### 1. `core/` —— 全局入口与服务 ⭐⭐⭐

| 文件 | 行数 | 职责 |
|---|---|---|
| **`MainEntryNew.kt`** | 72.9K | **全局大脑**。`initialize()` 组装全部依赖（LLM/工具/记忆/会话）；`runWithSession()` 为每个会话创建独立 AgentLoop 并驱动执行、收集进度、落盘、累计 token、触发记忆沉淀。**学本项目从这里入手。** |

## 六、建议学习路径

1. **先看数据流**（第二节）——一条指令怎么走完 Observe-Reason-Act。
2. **读 `core/MainEntryNew.kt` 的 `runWithSession()`** —— 看整个执行管线怎么串起来。
3. **读 `agent/loop/AgentLoop.kt`** —— 看循环怎么控制迭代、怎么路由工具。
4. **读 `agent/tools/device/DeviceTool.kt` 的 `snapshot` 和 `tap`** —— 看"感知 + 操作"如何落地。
5. **读 `providers/UnifiedLLMProvider.kt`** —— 看 LLM 怎么被调用（OpenAI 兼容 + 流式）。
6. **读 `agent/memory/` 三个子包** —— 看记忆三件套各自干什么。
7. **读 `agent/skills/SkillsLoader.kt` + `agent/behavior/`** —— 看 SKILL 怎么被"教学"出来并热加载。
8. **最后读 `ui/` 和 `remote/`** —— 看界面与远程入口怎么接上 Agent。
